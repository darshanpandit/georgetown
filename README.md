# Transportation Science: Past, Present & Future

Presentation and interactive visualizations on transportation modeling, created for Georgetown University.

## Viewing the Presentation

Open `index.html` in a browser to view the Reveal.js slide deck.

## Travel Molecule Visualization

Open `travel-molecule.html` for an interactive force-directed visualization of U.S. travel patterns:
- **Mode Molecule** — transport mode shares as atoms, multimodal trip chains as bonds
- **Activity Molecule** — daily activity chains colored by dominant transport mode

## Data Sources

Sample data is based on published mode share summaries from the [2017 National Household Travel Survey (NHTS)](https://nhts.ornl.gov/), conducted by the Federal Highway Administration.
